## 3. Design system e regras travadas

- **Paleta (manual):**

| Cor | Hex | Observação |
|---|---|---|
| magenta | `#9C1781` | No código também `#9C1782` (faixa de números) |
| teal | `#037E99` | `#047E99` na faixa |
| magenta-light (rosa) | `#F0B6F2` | Só fundo e brilho, **nunca texto** |
| teal-light (ciano) | `#68C0D4` | |
| brandgray | `#E1E1E1` | |
| ink | `#1A1420` | |
| ink-muted | `#5A5260` | |
| cream | `#FAF8F6` | |

- **Fonte:** só Poppins, servida pelo próprio site em `public/fonts`, nos pesos 300, 400, 500, 700 e 900. Não há 600 (o `font-semibold` cai no arquivo 700) nem itálico. Nunca importe fontes novas.
- **Contraste:**
  - teal sobre creme dá **4,46:1** e reprova AA para texto pequeno; teal só passa sobre branco puro (4,72);
  - texto branco só sobre magenta ou teal;
  - ciano `#68C0D4` só com texto ink.
- **Vocabulário proibido na copy**, que o verificador bloqueia:
  - **"100%"**, inclusive dentro de classes CSS como `at_100%` ou `calc(100%-…)`;
  - orçamento, preço, R$, promoção, desconto, garantido, indolor/sem dor, parcelamento, "sem compromisso", superlativos vazios;
  - "avaliação" no sentido de consulta ("avaliações" do Google pode).
- **Regras de conteúdo:**
  - nunca inventar depoimento, nome, número ou foto;
  - nunca usar banco de imagens;
  - nunca usar avatar com iniciais na equipe (nos depoimentos de paciente, iniciais são permitidas);
  - antes e depois exige autorização escrita do paciente e foto sem edição do resultado (Resolução CFO 196/2019), com legenda de autorização em cada caso.
- **Verificador:** exige exatamente um `<h1>`, a ordem das seções, a origem de cada CTA de WhatsApp (`data-cta`), 12 perguntas no FAQ com todas as respostas no HTML, nenhum `opacity:0` na hero e os schemas Dentist, LocalBusiness, FAQPage e Person.
- **Tags de seção:** teal, caixa alta, `tracking 0.18em`. Sob o H2 vem o `Simbolo` oficial (`src/components/ui/BrandGraphics.tsx`).

## 5. Histórico de erros (não repetir)

| Tentativa | Erro | Lição |
|---|---|---|
| Classes com `100%` (`at_100%_55%`, `calc(100%-24px)`, gradiente com `100%`) | Verificador reprova: "100%" na marcação | Use `at_right_55%`, `left-3 right-3 max-w-…` ou mova para CSS em `globals.css` |
| Commitar sem checar o verificador (`… ; npm run verificar \| grep; git commit`) | Commit `4977e66` foi ao ar com falha | Encadeie: `npm run verificar \| grep -q "0 falhou" && git commit …` |
| `npx shadcn init` | (evitado) Reescreveria tailwind e globals | Criar componentes base e tokens à mão |
| Passar `[--duration:28s]` por className num componente com `[--duration:40s]` | A classe perde por ordem do CSS | Use `cn` (tailwind-merge) ou `style` |
| Utilitário vs. classe de `@layer components` (`lg:rounded-none` + `lien-fundo`) | O utilitário sempre vence | Use utilitário arbitrário: `lg:rounded-[24px_120px_40px_160px]` |
| Pausar animação do `motion` com CSS `animation-play-state` ou `getAnimations()` | O `motion` anima por JS (transform inline) | Pausa por botão trocando para uma grade estática |
| Radix Accordion/Tabs sem `forceMount` | Resposta fechada some do HTML (SEO) | `forceMount`, mais CSS para ocultar o estado fechado |
| `forceMount` no AccordionContent | O Radix não aplica mais `hidden` | Regra CSS pelo `data-state` |
| `offsetLeft` de cards num trilho sem `position: relative` | Medido em relação a um ancestral; o 1º clique pulava para o último slide | Trilho de carrossel com `relative` |
| `onClick` de foco em painel com `visibility` em transição | Elemento `visibility:hidden` no instante 0 não recebe foco | Visibilidade imediata ao abrir (`.is-open`) |
| Medir contraste amostrando a caixa inteira do elemento | Falso negativo (área vazia) | Use `Range.getClientRects()` |
| Medir pegando o primeiro `img` da hero | Pegou o símbolo da marca | Seletor `picture img` |
| `npm i` / `npx` direto no Bash, com sandbox | Timeout de 120s | Rode em background ou com timeout maior |
| Script de imagem fora do projeto | `Cannot find module 'sharp'` | `NODE_PATH=$PWD/node_modules` |
| Brilho do fundo no topo da seção (como no original) | Etiqueta teal caía para 4,3:1 | Brilho a 55% da altura, raio menor no celular |
| Glow ou véu nas proporções do prompt da hero | Texto a 4,0–4,4:1 | Véu mais forte até 50% da largura (valores no `globals.css`) |
| Painel do navegador (Claude Browser) oculto | Capturas brancas, rAF/IntersectionObserver/vídeo pausados | Faça uma captura para forçar a pintura e meça pela API de animações ou por JS; não conclua "bug" pela captura branca |
| Dados fictícios de teste esquecidos | O auto-commit publicaria | Sempre restaure e confira com `grep -c "TESTE"` antes de terminar |
| `ffmpeg` não existe na máquina | | `npm i ffmpeg-static` numa pasta temporária (o scratchpad); nunca como dependência do projeto |
| `| head` num script node com várias saídas | EPIPE matou o script na metade | Não corte a saída de scripts que gravam arquivos |
